# 📧 Email Drafting AI Agent - FREE Version

A two-agent AI system that drafts professional emails without any API key!

**Architecture:** Context -> [Analyst Agent] -> Brief -> [Writer Agent] -> Final Email
**Inspired by:** ashishpatel26/500-AI-Agents-Projects

## 🚀 Features
- No OpenAI API Key Needed
- Two-Agent System (Analyst + Writer)
- Custom tone & recipient
- Saves output to .txt

## ▶️ How to Run
```bash
python agent.py --context "Your topic" --tone "professional" --recipient "your manager"
